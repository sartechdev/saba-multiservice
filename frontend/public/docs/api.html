Saba Multiservice API & Agent Docs

Bienvenido a la documentación para desarrolladores y agentes autónomos de Saba Multiservice. Proveemos servicios técnicos oficiales de reparación y venta de repuestos en Santa Fe Capital.

Especificación OpenAPI 3.1

La especificación completa en formato OpenAPI está disponible en: /openapi.json

Catálogo de APIs (RFC 9727)

El catálogo en formato linkset+json está publicado en: /.well-known/api-catalog

Recursos Principales

  • GET /api/health: Verificación de estado del servicio.
  • GET /api/products: Búsqueda en catálogo de repuestos y controles.
  • POST /api/quotes: Creación de solicitudes de presupuesto de reparación técnica.

Protocolos para Agentes de Inteligencia Artificial

  • ARD Manifest: /.well-known/ai-catalog.json
  • MCP Server Card (SEP-1649): /.well-known/mcp/server-card.json
  • Agent Skills Index: /.well-known/agent-skills/index.json
  • Auth.md: /auth.md
  • Markdown for Agents: Compatible con cabecera Accept: text/markdown en / o vía /llms.txt.
